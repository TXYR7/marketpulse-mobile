移动端流畅度与安卓底部导航修复（mp-mobile-20261111-2）

- 安卓 standalone/fullscreen/minimal-ui 在原生安全区不足时，底部至少预留 56 CSS px；普通浏览器保留 16px 下限和原生 safe-area。启动脚本在首屏绘制前执行，并响应显示模式变化。
- 导航、提示消息、边跳按钮、详情操作区共用安全区。390×844 和 320×740 下模拟 48px 系统按键栏，导航按钮分别止于 y=788 和 y=684，系统栏分别从 y=796 和 y=692 开始。320px 下详情关闭按钮止于 y=672，位于系统栏上方。
- 同页点击直接返回；导航先更新选中状态，内容延后一帧；行情更新合并呈现，只生成最后选中的页面。保留每页滚动、筛选和工具输入。
- 完整涨停池展开才生成卡片。日K补齐按同一快照批量处理，真实报价仍立即进入统一判决，未修改模型或公式。
- 长列表卡片启用 content-visibility；控件仅初始化一次；交互动效限制在当前页与可见弹层；工具历史统计与本地记录读取复用缓存。异步响应在页面隐藏时仅存缓存，返回时呈现。
