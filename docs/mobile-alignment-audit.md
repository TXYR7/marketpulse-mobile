# 手机界面与交互对齐检查

2026-11-10。对照当前网页源码检查手机工作区，保留手机的竖向布局与四个底部入口。

| 项目 | 修正与验证 |
| --- | --- |
| 基础材质 | 直接使用网页 tokens 与 color-identity：深色矿石黑/暖石墨，浅色象牙白/瓷白；清除旧蓝灰覆盖与星空背景 |
| 页面颜色 | 全市场金、打板铜、涨停琥珀、板块苔玉、热度玫瑰、买卖参考梅紫；详情石玉、设置岩砂 |
| 业务色 | 红涨绿跌、盈亏、风险、成功、情绪阶段沿用网页变量；普通数据不染成风险色 |
| 图表 | 蜡烛和成交量使用网页红绿，MA5/10/20恢复灰/蓝/橙；网格、十字线、文字和按钮随主题适配 |
| 主题切换 | 按钮显示太阳/月亮，记住设备偏好，首帧和状态栏颜色同步；使用网页揭幕、旋转和取消规则，不支持时走原生轻动画 |
| 快速操作 | 修复揭幕快照将点击目标报告为HTML、造成刷新或导航点击丢失的问题；只向固定操作补交付，不按变化的数据行推测旧画面的标的 |
| 手动刷新 | 顶栏、下拉和各排行更新入口统一请求与反馈；在途合并、短时节流；加载、成功、部分数据与失败分别显示，真实空池有效 |
| 刷新呈现 | 使用网页扫描线、转动、完成/失败图标与揭幕；失败保留旧数据；标题明确显示实际更新的页面 |
| 详情刷新 | 日K和板块成员都有加载、完成、降级/失败反馈；成员刷新保留搜索与滚动位置 |
| 更新时间 | 保留收盘标记和实际取数时间；排行使用本页快照时间；缓存、失败和缺源有明确提示 |
| 导航与筛选 | 同源星轨图标、页面色、连续选中层、按压与页间方向动画；分页回到列表开头，筛选不因刷新清空 |
| 弹层 | 详情按网页规则打开、关闭与重开；关闭立即禁用自身交互，旧回调不能隐藏新面板或抢走新弹层焦点 |
| 后台与减少动态效果 | 停止装饰动画，保留真实状态；不阻止数据更新 |
| 更新与维护 | 所有共享资源纳入离线外壳并同步版本；本机一键发布在存在相邻网页仓库时先同步主题、品牌、动效和刷新模块，再构建、测试与发布 |

验证包括127项原冒烟检查、47项行为测试，涵盖原18项通知、16项工作区、6项配色/刷新及7项网页动效边界测试。浏览器检查真实行情、深浅主题、320/390/768px、排行更新、均线、详情与快速操作。

`scripts/sync-workspace.mjs` 是共享源码同步入口；颜色、动效和刷新模块直接来自网页，手机适配保留在 mobile-identity.css、mobile-interactions.js 与 mobile-workspace.js。同步不替代手机布局实现。桌面后端回测、审计与回放的边界继续见 [功能对照](mobile-workspace.md)。
