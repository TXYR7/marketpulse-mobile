# 手机信号统计与回测（2026-11-11）

工具页新增折叠的“信号统计与回测”。手机继续独立运行，不访问电脑数据库，也不要求电脑开机。

信号保存在本机 IndexedDB。数据库从3升到4，只新增 `signals` 表，原有自选、设置、交易、复盘和历史表不清空。记录当前可信行情的评级、模式、价格与时间；历史回看、旧快照和不可信行情不补造实时观察。首次发现、首次进入S/A、最后一次评级变化分别保存和统计，首次分类不覆盖。重复行情、迟到观察不能改写较新的记录。新版规则指纹与现有 `unified-2.0.0` 判决版本一起保存，各版本不混用。

点击“更新统计”后，按需读取最多24只待结算股票的日K；结算至少等到真实下一交易日15:05以后。首次实时价格与前复权日K的前收盘口径不一致时保留待结算。信号统计是价格表现，未扣成交成本，不代表已执行的交易。完整结算日要求该日所有样本都有价格结果。不同版本原始观察仍保留并可导出。

手机收益回测与当前桌面 `backtest-2-date-ledger` 使用同一组纯函数和12个策略。`scripts/sync-research.mjs` 只转换模块边界和抽取计算函数；测试要求相同输入、资金和成交设置下结果完全一致。买入受阻保持现金，退出受阻保留市值和回撤；真实买入日执行T+1，同日候选共享现金，持仓浮亏使用含佣金的实际成本。

可选择10/20/30个已收盘市场交易日、本金和收盘/下一交易日开盘买入情景。先核验全部历史涨停池，任何日期缺失都不生成新报告。之后每次最多补录24只股票的日K，可重复点击继续补齐。界面显示价格覆盖和缺失来源；数据较少不代表完整策略表现，无成交样本单独显示。补录有进度与停止按钮，失败保留上次报告。研究价格缓存按记录时点检查，未收盘日K不作为最终结果。

所有策略使用相同市场日期边界；训练、验证、样本外按完整日期分组，并隔离跨段结果窗口。显示组合收益、回撤、仍持有股票、受阻数量、日期数量和隔离样本。日K仍是假设成交情景，不证明涨停排队成交，不模拟各证券不同申报数量或公司行动。

买卖参考同步新的1/3/5日不重叠收益窗口及基准，显示窗口数量。样本不足门槛继续使用，历史描述不当作独立前瞻胜率。

“导出本地资料”包含信号观察和最近一份手机回测。SQLite审计结算、逐分钟回放、参数账本和电脑备份继续在桌面运行。

维护：在手机版目录运行 `npm run sync:research`，从相邻桌面目录生成共享研究函数；其他位置使用 `MP_DESKTOP_ROOT`。构建后台包、运行手机测试、递增缓存版本后发布。既有判断模型、主题配色与通知配置保持当前版本。
