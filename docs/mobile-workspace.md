# 手机工作区 · 2026-11-10

2026-11-11 外观同步：共享网页最新的黑灰 / 白灰主题、暖金操作、紫色选择与数据、绿色排行分数、铜色热度及分级风险色。评级数字与实际评级绑定，风险数值增加等级文字，首板密度单独用紫色。数据状态、原始分数、判断模型与浏览器存储沿用手机版当前版本，缓存版本与资源地址一起更新。

数据边界：主线使用涨停池的行业代理；实时概念归因不冒充服务端完整概念库。板块涨停数只在完整成员与有效涨停池相交后展示，漏页或接口故障保持缺失。热榜备用源没有热度值时显示名次，缺失的热度/名次变化保持空值。日K前复权，量价不可比或历史缺失时判决标待补齐。

桌面依赖SQLite、服务端调度和完整历史补录的策略收益回测、审计结算、逐分钟回放、备份与参数账本仍在桌面运行。独立手机不生成这些服务端结果。手机交易仅查看已有记录与导出，新增实盘记录继续沿用桌面记账流程。

共享模块同步：在手机目录运行 `npm run sync:workspace`，默认从相邻 `../codex` 仓库读取。其他路径可通过 `MP_DESKTOP_ROOT` 指定。只转换 CommonJS 与 ES Module 的导入导出边界，规则源码保持一致。排行纯筛选函数也直接同步，手机布局独立实现。

验证：127项原冒烟检查、18项通知行为测试和16项新工作区测试。新测试覆盖判决结果与桌面对照、重复渲染的连续观察、零池/坏响应、排行组合筛选、原始名次分层、成员稳定分页、停牌空值、K线缓存及均线计算。新增界面与交互修正见 [对齐检查](mobile-alignment-audit.md)。浏览器使用真实行情检查导航、候选筛选、股票详情、板块成员、三个排行、买卖参考、320/390/768px与明暗主题。
