抽屉与移动端配色检查（mp-mobile-20261111-4）

本次逐项检查了主页面、市场列表、候选、涨停天梯、风险、详情、图表、设置及状态提示。主题和业务颜色仍取已有变量，仅修复消费位置和覆盖关系。

| 位置 | 修正后的用途 |
| --- | --- |
| 三个指数、股票列表和候选现价 | 按实际涨跌统一红/绿，平盘、停牌及缺失中性，不再被正文色覆盖 |
| 涨停/跌停数量 | 红/绿；真实零仍是有效数据 |
| 连板高度 | 保留网页的蓝色结构数据色 |

| 评级、主线排行、热度 | 保留既有分档、绿色强度数字与铜色热度，不用涨跌色暗示评分结果 |

抽屉优化：

- 移除原生标记和叠加的三角箭头，折叠标题用“展开/收起”文字提示。
- 使用两帧transform动画，打开240ms、关闭200ms；普通开关不测量高度，不生成61帧JS弹簧数据。连续开关从当前位置衔接；结束后释放合成层。
- 去掉整屏背景模糊和长折叠内容的高度过渡。抽屉固定92dvh，标题、页签、底部按钮固定，各分区独立滚动并记住位置。
- 拖动每个绘制帧只写一次位移，松手从拖动位置继续退出或回位，处理touchcancel。
- 历史晋级统计和相似日参考首次进入依据时才运行，且等待打开动画完成；缓存历史统计，过期响应不计算旧详情。
- 抽屉覆盖时暂缓后台页面重绘，关闭后一次呈现最新状态；真实行情观察、判决与当前详情字段继续更新。

检查结果：72项Node回归通过，模型比较无跳过。浏览器核对320×740浅色和390×844暗色、连续四轮开关、分区高度/滚动、60根日K、八维证据及配色，未发现页面错误、横向溢出或关闭后的动画层残留。
